# 命令、整理模型与柠檬黄活动验证

2026-10-25，分支 feat/v0.2。本轮按用户确认增加 `/wanxiang`、整理模型选择、真实待落库标题，以及节点本体和双活跃端点连线的柠檬黄活动效果。

## 行为与证据

- `/wanxiang [问题]` 注册到宿主原生命令目录，交给当前会话 AI 使用 knowledge_search / knowledge_read。空参数引用当前问题；不切换会话模型，不自动落库。执行前核验当前 Agent 可见工具，查询经 redacted()，引用知识不作为指令。
- 整理模型默认跟随来源会话模型，无来源配置时保持原宿主默认机制；可选择宿主公开目录中的 provider/model。只影响 AI 落库，原文导出不调用模型。指定模型消失时明确报错，不静默替换。
- 待落库展示当前真实标题；题示 ID 的实际标题为“思考逆向”。读取标题不会改写历史待落库文件；无法获取时显示“会话标题暂不可用”。
- 活跃节点本体使用 #edda00；真实已有连线只有两端同时活跃才变黄，不新增关系。约 1 秒轮询；最后 4 秒恢复原分类色。关闭活动后原色恢复。
