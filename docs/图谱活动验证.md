# 图谱金色活动验证（2026-10-25）

## 接入事实与边界

不新增宿主假定事件。知识调用从本插件 knowledgeTools 的 execute 成功返回处提取实际返回的条目 ID；knowledge_search / knowledge_read / knowledge_timeline 返回资料均视为 AI 工具读取。失败、空结果及仅普通页面浏览不发出事件。返回体仍走原 serialize/redacted 路径，活动不新增任何送模型内容。

自动注入沿已验证的 RecallService.section 路径，在 record.injected=true 时发送去重元数据；候选就绪、隐私未确认、超时、仅提示均不冒充注入。仍为 interpolate:false、section 只读已就绪结果。新增活动队列同步内存操作有界，无 I/O、搜索或模型调用。

落库从 saveJob 成功持久化 status=success 后产生事件；恢复中的实际成功写入同样可产生事件。启动不扫描历史成功任务回放活动。任意文件工具读写、模型是否在推理中真正采纳、未通过插件流程完成的外部文件修改，当前没有可靠的知识ID证据，因此不触发动画。

## 展示与限制

- 保留全部分类填充色和原布局。外围香槟金光环，前3.6秒沿已有边传播金点，12秒内淡出；一跳传播不表示邻居被模型读取。
- 内存仅保存 seq/at/kind/entryIds，不保存文本/查询/会话正文；队列最多128事件，每事件32ID；渲染保留最多32标记、每帧16光环/32光点。
- GET graph-activity 受原本地token校验。可见图谱每秒读取一次元数据，2秒超时、单请求、隐藏页暂停，销毁时中止。约1秒展示延迟，不拦截模型请求。
- 金色活动开关存本机localStorage；系统减少动画时静态光环，无连续活动动画。后台事件继续记录，但不用于后台假动画。
- 切库更换generation并清空旧事件，空图首次成功落库自动刷新。聚合只映射已返回且真实存在的簇，样本外条目不猜测映射。

端到端：scripts/ui-graph-activity.mjs 在临时合成库使用实际知识工具成功读取、真实落库、真实HTTP轮询及真实Canvas，验证开关关闭后配色像素完全恢复、减少动画停帧、球体/网络切换、切库到空库后首次落库与销毁。已安装包同一脚本5组通过；不调用在线provider，不触碰个人库。原图谱旋转交互8项、已安装包常规UI15项通过。
