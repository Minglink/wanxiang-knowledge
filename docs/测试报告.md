# 万象知识库 0.1.0 测试报告

测试日期：2026-10-24。测试环境：Windows、DeepSeek Harness Desktop `0.2.1-alpha.1`。

| 验证层级 | 结果 |
| --- | --- |
| TypeScript 检查与构建 | 通过 |
| 核心自动化测试 | 11 项通过 |
| 实际宿主运行时契约 | 工具 schema、输出渲染、Session 事件和 Zstandard 持久化通过 |
| 真实宿主接口 | 会话读取、原文落库、去重、中文搜索、编辑、索引重建、工具检测及模型整理通过 |
| 真实宿主页面自动化 | 10 项通过；没有页面运行异常 |
| 安装核验 | 已安装源码与构建文件一致；历史会话及标题读取正常 |

核心测试覆盖文件发布、增量落库保留手工编辑、取消与重试、模型输出及来源校验、部分文件写入失败恢复、索引恢复、目录切换和外部修改保护。

模型整理测试使用独立创建的合成会话，调用宿主已经配置的 `deepseek-official/deepseek-flash`。生成了笔记和知识卡片，重复执行没有重复调用模型。

界面自动化在隔离的无头 Chrome 中连接实际 Harness 页面，覆盖会话选择、一键落库、中文搜索、详情编辑、工具登记与版本检测、页签切换、设置面板、窄屏和快捷面板。

原生桌面检查确认了侧栏入口能够挂载。桌面自动化随后因无法可靠识别窗口网址而停止，最终 Electron 窗口中的完整点击回归未完成。

原始本机测试数据、会话来源摘录、安装备份和环境配置不包含在源码仓库中。可以按 README 的命令运行核心测试；`scripts/runtime-contract.mjs`、`scripts/live-check.mjs` 和 `scripts/ui-live.mjs` 用于安装了对应 Harness 版本的本机集成验证。

尚未验证：其他宿主版本兼容性、一万条知识的性能、附件 OCR 和向量检索。
