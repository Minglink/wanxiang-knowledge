# Win32 A/W 接口：字符编码与长度单位

Windows 许多文本接口区分 A 与 W 版本。阅读调用时应先确认真实入口和数据编码，再解释缓冲区，而不是仅根据字符串外观猜测。

缓冲区容量可能以字符数计，也可能以字节数计，应以具体参数契约为准。宽字符数据被当作单字节字符串时，夹在字符之间的零字节会让显示提前结束；反向解释则可能把相邻字节组合成错误字符。

分析记录应包含原始字节、声明长度及解码方式。宏名或工程选项影响源代码最终选择的接口，反汇编分析则应核对实际调用目标。

分析例（本库构造，未执行）：例如只含BMP字符的文本AB，以UTF-16表示时正文占4字节，若还包括结尾零字符则占6字节。接口要求字符容量还是字节容量，会直接影响需要分配和检查的范围。
