# CWE-641: 对文件和其他资源名称的不当限制

## 缺陷定义

该产品使用来自上游组件的输入构建文件或其他资源的名称，但未对所得名称进行限制或限制不当。

## 机制与扩展说明

这可能会导致相关的弱点。例如，如果这些资源的名称包含脚本字符，则如果应用程序在动态生成的网页上显示资源名称，脚本可能会在客户端浏览器中执行。或者，如果资源被某些应用程序解析器使用，特制的名称可能会利用解析器内部的某些漏洞，从而可能导致在服务器机器上执行任意代码。问题将根据此类畸形资源名称的使用上下文以及目标技术中是否存在漏洞或所做的假设而异，这些漏洞或假设可能导致代码执行。

## 官方英文定义（核对锚点）

Improper Restriction of Names for Files and Other Resources

The product constructs the name of a file or other resource using input from an upstream component, but it does not restrict or incorrectly restricts the resulting name.
