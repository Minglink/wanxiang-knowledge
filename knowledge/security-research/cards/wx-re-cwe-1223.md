# CWE-1223: 一次性写入属性的竞争条件

## 缺陷定义

硬件设计中的一次性写入寄存器比受信任软件组件更早地被不受信任软件组件编程，导致出现竞争条件问题。

## 机制与扩展说明

集成电路和硬件 IP 的软件可编程控制和设置通常存储在寄存器电路中。这些寄存器内容必须在硬件复位时初始化为硬件单元硬件描述语言（HDL）代码中硬编码定义的默认值。一种常用的安全保护方法是使寄存器设置为“一次性写入”（write-once），以防止被软件修改。这意味着硬件实现仅允许软件向此类寄存器写入一次，写入后它们即变为只读。这对于允许初始引导软件将系统设置配置为安全值，同时阻止运行时软件修改此类硬件设置非常有用。
此类控制硬件设计中的实现问题可能使这些寄存器暴露于竞争条件安全漏洞中。例如，考虑一个硬件设计，其中有两个不同的软件/固件模块并行执行。一个是受信任的模块（模块 A），另一个是不受信任的模块（模块 B）。在这种设计中，模块 B 有可能在模块 A 之前向一次性写入寄存器发送写周期。由于该字段是一次性写入的，模块 A 编程的值将被忽略，而由模块 B 抢先编程的值将被硬件使用。

## 官方英文定义（核对锚点）

Race Condition for Write-Once Attributes

A write-once register in hardware design is programmable by an untrusted software component earlier than the trusted software component, resulting in a race condition issue.
