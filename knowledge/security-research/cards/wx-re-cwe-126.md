# CWE-126: 缓冲区越界读取

## 缺陷定义

产品使用引用目标缓冲区之后内存位置的缓冲区访问机制（如索引或指针）来读取缓冲区。

## 可能后果及作用范围

此表指定了与该弱点相关的不同个体后果。“范围”识别被违规的应用安全领域，而“影响”描述如果攻击者成功利用该弱点所产生的负面技术影响。“可能性”提供有关相对于列表中其他后果，特定后果被预期的可能性信息。例如，某种弱点可能极有可能被利用以实现某种影响，但利用它来实现另一种影响的可能性则很低。

范围：机密性
绕过保护机制
范围：机密性
通过越界读取内存，攻击者可能获取机密值（如内存地址），从而绕过 ASLR 等保护机制，以提高利用其他弱点实现代码执行而非仅仅导致拒绝服务的可靠性和可能性。
DoS：崩溃、退出或重启
范围：可用性，完整性
攻击者可能通过诱导产品读取不允许的内存位置（如段错误）来导致崩溃或其他拒绝服务，或者诱导读取操作返回比预期更多的数据。

## 补充说明与边界

关系
这些问题可能是由于缺少哨兵值（
CWE-463
）或信任用户输入的长度变量所致。
其他
缓冲区越界读取通常发生在指针或其索引被递增到缓冲区末尾之后，或者当指针算术结果指向有效内存位置之后的位置时。

## 官方英文定义（核对锚点）

Buffer Over-read

The product reads from a buffer using buffer access mechanisms such as indexes or pointers that reference memory locations after the targeted buffer.
