# CWE-34: 路径遍历: '....//'

## 缺陷定义

产品使用外部输入来构建应该在受限目录内的路径名，但它没有正确中和可能解析为该目录之外的位置的“....//”（双点点斜杠）序列。

## 机制与扩展说明

这允许攻击者遍历文件系统，从而访问受限目录之外的文件或目录。
'....//' 操作可用于绕过某些路径遍历保护方案。如果像某些正则表达式引擎那样顺序过滤 "../"，那么 "....//" 可能会塌陷为不安全的 "../" 值（
CWE-182
）。当操作系统将 "//" 和 "/" 视为等效时，如果 ".." 被删除，这也可能非常有用。

## 可能后果及作用范围

此表指定了与该弱点相关的不同个体后果。“范围”识别被违规的应用安全领域，而“影响”描述如果攻击者成功利用该弱点所产生的负面技术影响。“可能性”提供有关相对于列表中其他后果，特定后果被预期的可能性信息。例如，某种弱点可能极有可能被利用以实现某种影响，但利用它来实现另一种影响的可能性则很低。

在执行输入验证时，考虑所有潜在相关的属性，包括长度、输入类型、可接受值的全部范围、缺失或额外的输入、语法、跨相关字段的一致性以及对业务规则的符合性。作为业务规则逻辑的一个例子，“boat”在语法上可能是有效的，因为它只包含字母数字字符，但如果输入只预期包含“red”或“blue”等颜色，则它无效。

CWE-182

## 官方英文定义（核对锚点）

Path Traversal: '....//'

The product uses external input to construct a pathname that should be within a restricted directory, but it does not properly neutralize '....//' (doubled dot dot slash) sequences that can resolve to a location that is outside of that directory.
