# CWE-1282: 假设不可变的数据存储在可写内存中

## 缺陷定义

不可变数据（例如第一阶段引导加载程序、设备标识符和“一次性写入”配置设置）存储在可写内存中，这些内存可以在现场被重新编程或更新。

## 机制与扩展说明

安全服务（如安全启动、代码和数据的身份验证以及设备远程证明）都需要一些被隐式信任的资产，例如第一阶段引导加载程序、公钥、黄金哈希摘要等。将这些资产存储在只读内存 (ROM)、熔丝 (fuses) 或一次性可编程 (OTP) 内存中可以提供强大的完整性保证，并为保障系统的其余部分提供信任根。如果被假设为不可变的资产可以被修改，安全性将会丧失。

## 官方英文定义（核对锚点）

Assumed-Immutable Data is Stored in Writable Memory

Immutable data, such as a first-stage bootloader, device identifiers, and "write-once" configuration settings are stored in writable memory that can be re-programmed or updated in the field.
