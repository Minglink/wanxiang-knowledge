# CWE-786: 在缓冲区起始位置之前访问内存

## 缺陷定义

产品使用引用缓冲区起始位置之前内存位置的索引或指针来读取或写入缓冲区。

## 机制与扩展说明

这种情况通常发生在以下场景：指针或其索引被递减到缓冲区之前的位置，指针算术运算导致位置指向有效内存起始地址之前，或者使用了负索引。

## 可能后果及作用范围

此表指定了与该弱点相关的不同个体后果。“范围”识别被违规的应用安全领域，而“影响”描述如果攻击者成功利用该弱点所产生的负面技术影响。“可能性”提供有关相对于列表中其他后果，特定后果被预期的可能性信息。例如，某种弱点可能极有可能被利用以实现某种影响，但利用它来实现另一种影响的可能性则很低。
影响
详细信息
读取内存
范围：机密性
对于越界读取，攻击者可能获得对敏感信息的访问权限。如果敏感信息包含系统详情（例如当前缓冲区在内存中的位置），这些知识可用于策划进一步的攻击，并可能产生更严重的后果。
修改内存；拒绝服务 (DoS)：崩溃、退出或重启
范围：完整性、可用性
越界内存访问极有可能导致相关内存甚至指令被破坏，从而可能导致程序崩溃。
修改内存；执行未经授权的代码或命令
范围：完整性
如果被破坏的内存可以被有效控制，则有可能执行任意代码。如果被破坏的是数据而非指令，系统将带着不当的变更继续运行，这可能违反隐式或显式的策略。

## 官方英文定义（核对锚点）

Access of Memory Location Before Start of Buffer

The product reads or writes to a buffer using an index or pointer that references a memory location prior to the beginning of the buffer.
