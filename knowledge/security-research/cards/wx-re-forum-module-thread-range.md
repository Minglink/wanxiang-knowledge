# 模块范围关联：线程启动地址与当前指令的区别

模块可表示为基址起始、映像大小限定的半开区间。检查地址归属时需先防止基址加大小溢出，并把刚好等于结束位置的地址排除在该模块外。

系统记录的线程启动地址与线程此刻正在执行的指令地址不同。一个正常模块内的启动入口，也不能说明线程后续只在该模块运行。

未落入枚举模块范围的地址，是进一步核验内存类型、映射状态和快照完整性的线索，不足以单独判定恶意代码。磁盘签名、加载映像与实际执行页也应分开记录。

分析例（本库构造，未执行）：例如模块基址为0x1000、大小为0x500，有效范围是[0x1000,0x1500)。地址0x1500不能归入该模块，即便显示时看上去只差一个边界；还应检查该地址所属的实际映射。
