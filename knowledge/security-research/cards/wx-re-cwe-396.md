# CWE-396：声明捕获通用异常

## 缺陷定义

捕获过于宽泛的异常会促使编写复杂的错误处理代码，而这些代码往往更易包含安全漏洞。

## 机制与扩展说明

多个 catch 块可能会显得冗长且重复，但通过捕获 Exception 等高级类来“精简” catch 块，可能会掩盖那些需要特殊处理或在程序当前阶段不应被捕获的异常。捕获过于宽泛的异常实际上违背了语言类型化异常的目的。如果程序随着开发不断增长并开始抛出新型异常，这种做法会变得尤为危险。新的异常类型将无法得到任何关注。

## 官方英文定义（核对锚点）

Declaration of Catch for Generic Exception

Catching overly broad exceptions promotes complex error handling code that is more likely to contain security vulnerabilities.
