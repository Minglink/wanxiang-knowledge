# CWE-22: 对受限目录的路径名限制不当（“路径遍历”）

## 缺陷定义

产品使用外部输入来构造一个路径名，旨在标识位于受限父目录下的文件或目录，但产品未正确中和路径名中的特殊元素，这可能导致路径名解析到受限目录之外的位置。

## 机制与扩展说明

许多文件操作旨在受限目录内进行。通过使用诸如“..”和“/”分隔符等特殊元素，攻击者可以逃逸出受限位置，从而访问系统其他位置的文件或目录。最常见的特殊元素之一是“../”序列，在大多数现代操作系统中，它被解释为当前位置的父目录。这被称为相对路径遍历。路径遍历还涵盖了使用绝对路径名（如“/usr/local/bin”）来访问意外文件的情况。这被称为绝对路径遍历。

## 可能后果及作用范围

此表指定了与该弱点相关的不同个体后果。“范围”识别被违规的应用安全领域，而“影响”描述如果攻击者成功利用该弱点所产生的负面技术影响。“可能性”提供有关相对于列表中其他后果，特定后果被预期的可能性信息。例如，某种弱点可能极有可能被利用以实现某种影响，但利用它来实现另一种影响的可能性则很低。

攻击面减少

这大大降低了攻击者绕过基础程序中存在但包含文件中不存在的任何保护机制的可能性。它还将减少攻击面。

确保错误消息仅包含对目标受众有用的最小细节，而不包含其他信息。消息需要在过于隐晦（可能使用户感到困惑）和过于详细（可能泄露不该泄露的信息）之间取得平衡。消息不应泄露用于确定错误的具体方法。攻击者可以利用详细信息来完善或优化其原始攻击，从而增加成功的可能性。

## 补充说明与边界

关系
路径名等价性可被视为一种规范化错误。
关系
一些路径名等价性问题与目录遍历没有直接关系，而是用于绕过关于文件/目录是否可被攻击者访问的安全相关检查（例如，文件名末尾的“/”可以绕过不期望末尾有 / 的访问规则，导致服务器在通常不会提供文件的情况下提供了文件）。
术语
与其他缺陷一样，术语通常基于所使用的操作类型，而不是潜在的缺陷。有些人仅使用“目录遍历”来指代插入“..”及等效序列的行为，这些序列的具体含义是遍历目录。
其他变体如“绝对路径名”和“驱动器号”具有目录遍历的*效果*，但有些人可能不会这样称呼它，因为它不涉及“..”或等效序列。
研究差距
许多路径遍历攻击的变体在根本原因方面可能研究不足。
CWE-790
和
CWE-182
开始填补部分空白。
研究差距
对漏洞的不完整诊断或报告可能会使人难以知道哪个变体受到影响。例如，研究人员可能会说“.. \”是易受攻击的，但没有测试可能同样易受攻击的“../”。
目录分隔符（“/”、“\”等）和“.”数量（例如“....”）的任何组合都可能产生独特的变体；例如，未列出“//../”变体 (CVE-2004-0325)。请参阅此条目的子条目和更低级别的后代。
其他
在许多编程语言中，空字节（0 或 NUL）的注入可能允许攻击者截断生成的路径名，从而将其应用于更广泛的文件范围。例如，产品可能会向任何路径名添加“.txt”，从而将攻击者限制在文本文件中，但空注入可能会有效地消除此限制。

## 官方英文定义（核对锚点）

Improper Limitation of a Pathname to a Restricted Directory ('Path Traversal')

The product uses external input to construct a pathname that is intended to identify a file or directory that is located underneath a restricted parent directory, but the product does not properly neutralize special elements within the pathname that can cause the pathname to resolve to a location that is outside of the restricted directory.
