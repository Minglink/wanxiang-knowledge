# CWE-456：变量初始化缺失

## 缺陷定义

该产品未初始化关键变量，这导致执行环境使用意外的值。

## 可能后果及作用范围

## 补充说明与边界

关系
此弱点是导致多种后果性弱点的主要因素，特别是在允许全局变量初始化（如 PHP）且库可被直接请求的 Web 应用程序中。
研究差距
很有可能大量的后果性弱点都将缺失初始化作为主要因素，但研究报告通常不提供此级别的详细信息。

## 官方英文定义（核对锚点）

Missing Initialization of a Variable

The product does not initialize critical variables, which causes the execution environment to use unexpected values.
