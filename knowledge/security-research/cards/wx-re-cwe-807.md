# CWE-807: 依赖不可信输入进行安全决策

## 缺陷定义

产品使用了一种依赖输入的存在或值的保护机制，但该输入可以由未受信任的参与者以绕过保护机制的方式进行修改。

## 机制与扩展说明

开发人员可能会假设诸如 Cookie、环境变量和隐藏表单字段之类的输入无法被修改。然而，攻击者可以使用自定义客户端或其他攻击手段来更改这些输入，且此类更改可能无法被检测到。当基于这些输入的值做出身份验证和授权等安全决策时，攻击者便能绕过软件的安全保护。
若没有足够的加密、完整性校验或其他机制，任何源自外部的输入都不可信。

## 可能后果及作用范围

此表指定了与该弱点相关的不同个体后果。“范围”识别被违规的应用安全领域，而“影响”描述如果攻击者成功利用该弱点所产生的负面技术影响。“可能性”提供有关相对于列表中其他后果，特定后果被预期的可能性信息。例如，某种弱点可能极有可能被利用以实现某种影响，但利用它来实现另一种影响的可能性则很低。

## 官方英文定义（核对锚点）

Reliance on Untrusted Inputs in a Security Decision

The product uses a protection mechanism that relies on the existence or values of an input, but the input can be modified by an untrusted actor in a way that bypasses the protection mechanism.
