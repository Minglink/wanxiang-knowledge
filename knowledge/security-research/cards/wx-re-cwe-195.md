# CWE-195: 有符号到无符号转换错误

## 缺陷定义

产品使用有符号原始类型并执行到无符号原始类型的强制转换，如果有符号原始类型的值不能使用无符号原始类型表示，这可能会产生意外的值。

## 机制与扩展说明

依赖有符号数和无符号数之间的隐式转换是危险的，因为结果可能会呈现出意想不到的值，并违背程序所做的假设。
函数通常会返回负值来表示失败。当函数的结果被用作大小参数时，使用这些负的返回值可能会产生意想不到的结果。例如，如果将负的大小值传递给标准内存复制或分配函数，它们将被隐式转换为较大的无符号值。这可能导致可被利用的缓冲区溢出或下溢情况。

## 官方英文定义（核对锚点）

Signed to Unsigned Conversion Error

The product uses a signed primitive and performs a cast to an unsigned primitive, which can produce an unexpected value if the value of the signed primitive can not be represented using an unsigned primitive.
