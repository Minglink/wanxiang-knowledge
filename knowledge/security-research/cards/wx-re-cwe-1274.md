# CWE-1274：包含引导代码的易失性内存访问控制不当

## 缺陷定义

产品执行安全引导过程，将引导加载程序代码从非易失性内存 (NVM) 传输到易失性内存 (VM)，但它对易失性内存缺乏足够的访问控制或其他保护措施。

## 机制与扩展说明

攻击者可能绕过安全启动过程，执行他们自己不可信的恶意启动代码。
作为安全启动过程的一部分，片上系统（SoC）或其他系统的只读存储器（ROM）代码从非易失性存储器（NVM）获取引导加载程序代码，并将其存储在易失性存储器（VM）中，例如动态随机存取存储器（DRAM）或静态随机存取存储器（SRAM）。NVM 通常位于 SoC 外部，而 VM 则位于 SoC 内部。当代码从 NVM 传输到 VM 时，它会通过 SoC 的 ROM 代码进行认证。

## 官方英文定义（核对锚点）

Improper Access Control for Volatile Memory Containing Boot Code

The product conducts a secure-boot process that transfers bootloader code from Non-Volatile Memory (NVM) into Volatile Memory (VM), but it does not have sufficient access control or other protections for the Volatile Memory.
