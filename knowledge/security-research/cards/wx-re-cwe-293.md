# CWE-293: 使用 Referer 字段进行身份验证

## 缺陷定义

HTTP 请求中的 referer 字段可以被轻易修改，因此它不是一个有效的消息完整性检查手段。

## 可能后果及作用范围

此表指定了与该弱点相关的不同个体后果。“范围”识别被违规的应用安全领域，而“影响”描述如果攻击者成功利用该弱点所产生的负面技术影响。“可能性”提供有关相对于列表中其他后果，特定后果被预期的可能性信息。例如，某种弱点可能极有可能被利用以实现某种影响，但利用它来实现另一种影响的可能性则很低。

获取特权或冒充身份
范围: 访问控制
否则可能未经授权的操作，可以被执行，就像它们已被引用服务器验证过一样。

## 预防与缓解措施

架构与设计
为了有效地检查给定操作是否已授权，必须使用某种强身份验证和方法保护手段。使用其他不能被简单伪造的授权方式。可能的选择包括用户名/密码或证书。

## 背景机制

HTML 请求中的 referer 字段可以被恶意用户轻易修改，使其在检查相关请求的有效性方面变得毫无用处。

## 官方英文定义（核对锚点）

Using Referer Field for Authentication

The referer field in HTTP requests can be easily modified and, as such, is not a valid means of message integrity checking.
