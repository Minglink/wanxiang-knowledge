# CWE-639: 通过用户可控键导致的授权绕过

## 缺陷定义

系统的授权功能未能防止用户通过修改标识数据的键值来获取其他用户的数据或记录。

## 机制与扩展说明

系统根据受用户控制的某个键值来检索用户记录。该键通常标识系统中存储的用户相关记录，并用于查找该记录以呈现给用户。攻击者很可能必须是系统中的已认证用户。然而，授权过程并未正确检查数据访问操作，以确保执行该操作的已认证用户拥有执行所请求数据访问的足够权限，从而绕过了系统中存在的任何其他授权检查。
例如，攻击者可以查看检索用户特定数据的位置（如搜索屏幕），并确定所查找项目的键是否可在外部进行控制。该键可能是 HTML 表单中的隐藏字段，也可能作为 URL 参数或未加密的 Cookie 变量传递；在这些情况下，都有可能对键值进行篡改。
此弱点的一种表现形式是：系统使用顺序的或容易被猜测的会话 ID，这允许一个用户轻易地切换到另一个用户的会话并读取/修改其数据。

## 官方英文定义（核对锚点）

Authorization Bypass Through User-Controlled Key

The system's authorization functionality does not prevent one user from gaining access to another user's data or record by modifying the key value identifying the data.
