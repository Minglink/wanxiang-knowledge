# CWE-226: 资源在重新使用前未清除敏感信息

## 缺陷定义

产品释放内存或文件等资源以便重用，但在产品执行关键状态转换或使其他实体能够重用该资源之前，未清除或“归零”资源中包含的信息。

## 机制与扩展说明

当资源被释放时，它们可能会被提供给后续使用。例如，内存被解除分配后，操作系统可能会将该内存提供给另一个进程；或者文件被删除时，磁盘空间可能会被重新分配。由于清除信息需要时间和额外的资源，操作系统通常不会清除之前写入的信息。
即使资源由同一进程重用，如果新数据的大小小于旧数据，此缺陷仍可能出现，这会导致旧数据的一部分仍然可访问。在数据长度可变但相关数据结构不可变的其他情况下，也会发生类似的错误。如果内存在使用后未被清除，那么当内存被重新分配时，这些信息可能会被不可信的方读取。
此缺陷适用于硬件，例如当设备或系统在正常操作期间切换电源、睡眠或调试状态，或者执行切换到不同的用户或权限级别时。

## 官方英文定义（核对锚点）

Sensitive Information in Resource Not Removed Before Reuse

The product releases a resource such as memory or a file so that it can be made available for reuse, but it does not clear or "zeroize" the information contained in the resource before the product performs a critical state transition or makes the resource available for reuse by other entities.
