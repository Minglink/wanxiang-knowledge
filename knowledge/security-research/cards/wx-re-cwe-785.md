# CWE-785: 使用无最大容量缓冲区的路径操作函数

## 缺陷定义

产品调用了一个用于规范化路径或文件名的函数，但它提供的输出缓冲区小于最大可能尺寸（例如 PATH_MAX）。

## 机制与扩展说明

将容量不足的输出缓冲区传递给路径操作函数可能会导致缓冲区溢出。此类函数包括 realpath()、readlink()、PathAppend() 等。

## 背景机制

Windows 提供了大量用于操作包含文件名的缓冲区的实用函数。在大多数情况下，结果会返回到作为输入传入的缓冲区中。（通常是在原位修改文件名。）大多数函数要求缓冲区至少为 MAX_PATH 字节长，但您应该单独检查每个函数的文档。如果缓冲区不足以存储操作的结果，则可能会发生缓冲区溢出。

Use of Path Manipulation Function without Maximum-sized Buffer

The product invokes a function for normalizing paths or file names, but it provides an output buffer that is smaller than the maximum possible size, such as PATH_MAX.
