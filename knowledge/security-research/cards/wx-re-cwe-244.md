# CWE-244: 释放前未正确清除堆内存（“堆检查”）

## 缺陷定义

使用 realloc() 调整存储敏感信息的缓冲区大小时，可能会使敏感信息暴露于攻击风险中，因为它并未从内存中移除。

## 机制与扩展说明

当密码或加密密钥等敏感数据未从内存中清除时，攻击者可能会使用“堆检查”攻击，通过内存转储或其他方法读取这些敏感数据。realloc() 函数通常用于增加已分配内存块的大小。此操作通常需要将旧内存块的内容复制到新的更大的内存块中。该操作会使原始块的内容保持完整但程序无法访问，从而导致程序无法从内存中清除敏感数据。如果攻击者随后能够检查内存转储的内容，敏感数据可能会被泄露。

## 官方英文定义（核对锚点）

Improper Clearing of Heap Memory Before Release ('Heap Inspection')

Using realloc() to resize buffers that store sensitive information can leave the sensitive information exposed to attack, because it is not removed from memory.
