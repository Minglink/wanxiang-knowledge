# CWE-1330: 内存擦除后剩余数据可读

## 缺陷定义

存储在内存电路中的机密信息在被清除或擦除后仍然可读或可恢复。

## 机制与扩展说明

当存储的内存内容在“清除”或“擦除”操作后没有完全丢失时，就会发生数据残留。机密内存内容仍然可以通过硬件中的数据残留被读取。
数据残留可能由于“清除”或“擦除”操作期间的性能优化或内存组织方式而发生，例如某种设计允许仅擦除内存组织元数据（如文件指针）而不擦除实际的内存内容。为了防范此弱点，内存设备通常会支持用于优化内存擦除和显式安全擦除的不同指令。
数据残留也可能由于所使用内存电路的物理特性而发生。例如，静态随机存取存储器 (SRAM) 和动态随机存取存储器 (DRAM) 的数据保持能力基于内存单元中保留的电荷，这取决于电源电压、刷新率和温度等因素。
除显式擦除指令外，自加密安全内存设备还可以通过加密擦除指令支持安全擦除。在此类设计中，仅擦除存储在设备上的加密数据的解密密钥。也就是说，加密擦除后，存储的数据在介质上仍然是残留的。然而，只有加密数据可以被提取。因此，此类设计中对数据恢复的保护依赖于加密算法的强度。

## 官方英文定义（核对锚点）

Remanent Data Readable after Memory Erase

Confidential information stored in memory circuits is readable or recoverable after being cleared or erased.
