# CWE-287：身份验证不当

## 缺陷定义

当一个参与者声称拥有特定身份时，产品未能证明或未能充分证明该声明是正确的。

## 可能后果及作用范围

此表指定了与该弱点相关的不同个体后果。“范围”识别被违规的应用安全领域，而“影响”描述如果攻击者成功利用该弱点所产生的负面技术影响。“可能性”提供有关相对于列表中其他后果，特定后果被预期的可能性信息。例如，某种弱点可能极有可能被利用以实现某种影响，但利用它来实现另一种影响的可能性则很低。
影响
详细信息
读取应用数据；获取权限或冒充身份；执行未经授权的代码或命令
范围：完整性、机密性、可用性、访问控制
这种弱点可能导致资源或功能暴露给非预期主体，可能为攻击者提供敏感信息，甚至执行任意代码。

## 检测与审计方法

详细信息
自动化静态分析
自动静态分析对于检测某些类型的身份验证很有用。工具可以分析相关的配置文件，例如 Apache Web 服务器中的 .htaccess，或检测常用身份验证库的使用情况。
通常，自动化静态分析工具难以检测自定义的身份验证方案。此外，软件的设计可能包含任何用户都可以访问且不需要建立身份的功能；检测缺乏身份验证的自动化技术可能会报告误报。
