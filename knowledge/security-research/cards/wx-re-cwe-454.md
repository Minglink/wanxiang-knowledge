# CWE-454: 信任变量或数据存储的外部初始化

## 缺陷定义

该产品使用可由不受信任的操作者修改的输入来初始化关键的内部变量或数据存储。

## 机制与扩展说明

产品系统应谨慎对待在信任边界之外初始化的变量，特别是当这些变量由用户初始化时。这些变量可能已被错误地初始化。如果攻击者能够初始化该变量，他们就可以影响易受攻击系统的行为。

策略：
输入验证
产品系统应谨慎对待在信任边界之外初始化的变量。在依赖信任边界之外的输入时，请确保执行充分的检查（例如输入验证）。
架构与设计
避免任何对变量的外部控制。如果必要，使用允许列表限制可修改的变量，并尽可能使用不同的命名空间或命名约定。

## 官方英文定义（核对锚点）

External Initialization of Trusted Variables or Data Stores

The product initializes critical internal variables or data stores using inputs that can be modified by untrusted actors.
