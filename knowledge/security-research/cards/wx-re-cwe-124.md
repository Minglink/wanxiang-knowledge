# CWE-124: 缓冲区写下溢（'缓冲区下溢'）

## 缺陷定义

产品使用引用缓冲区起始位置之前内存位置的索引或指针向缓冲区进行写入。

## 可能后果及作用范围

此表指定了与该弱点相关的不同个体后果。“范围”识别被违规的应用安全领域，而“影响”描述如果攻击者成功利用该弱点所产生的负面技术影响。“可能性”提供有关相对于列表中其他后果，特定后果被预期的可能性信息。例如，某种弱点可能极有可能被利用以实现某种影响，但利用它来实现另一种影响的可能性则很低。
影响
详细信息
修改内存；拒绝服务 (DoS)：崩溃、退出或重启
范围：完整性、可用性
越界内存访问极有可能导致相关内存甚至指令的破坏，并可能导致崩溃。
执行未经授权的代码或命令；修改内存；绕过保护机制；其他
范围: 完整性、机密性、可用性、访问控制、其他
如果被破坏的内存可以被有效控制，则可能执行任意代码。如果被破坏的内存是数据而不是指令，系统将带着不当的更改继续运行，这可能违反隐式或显式的策略。后果仅受限于受影响数据的使用方式，例如使用相邻的内存位置来判断用户是否具有特殊权限。
绕过保护机制；其他
范围：访问控制，其他
当后果是任意代码执行时，这通常可以用来破坏任何其他安全服务。

## 官方英文定义（核对锚点）

Buffer Underwrite ('Buffer Underflow')

The product writes to a buffer using an index or pointer that references a memory location prior to the beginning of the buffer.
