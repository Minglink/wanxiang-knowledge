# CWE-567: 多线程环境下的共享数据共享数据同步访问缺失

## 缺陷定义

产品未能正确同步共享数据（例如跨线程的静态变量），这可能导致未定义的行为和不可预测的数据更改。

## 机制与扩展说明

在 Servlet 中，共享静态变量不会自动受到并发访问的保护，而 Servlet 本身是多线程的。这是 J2EE 应用中一个典型的编程错误，因为多线程是由框架处理的。当共享变量受到攻击者的影响时，一个线程可能会将该变量修改为对另一个正在使用该变量的线程无效的数据。
请注意，此弱点并非 Servlet 所独有。

## 预防与缓解措施

阶段
缓解措施
实施
移除 Servlet 之间使用的静态变量。如果无法避免，请对这些变量使用同步访问（synchronized access）。

## 官方英文定义（核对锚点）

Unsynchronized Access to Shared Data in a Multithreaded Context

The product does not properly synchronize shared data, such as static variables across threads, which can lead to undefined behavior and unpredictable data changes.
