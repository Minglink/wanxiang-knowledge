# CWE-1276：硬件子模块与父系统连接不正确

## 缺陷定义

硬件 IP 与父系统设计之间的信号连接不正确，从而导致安全风险。

## 机制与扩展说明

单个硬件 IP 必须与父系统通信，产品才能正常且按预期运行。如果实施不正确，即使没有导致任何明显的功能问题，也可能导致安全问题。例如，如果 IP 只能通过系统范围的硬复位进行复位，但复位输入却连接到软件触发的调试模式复位（该复位在硬复位期间也会被置位），则 IP 内部的数据完整性可能会受到损害。
