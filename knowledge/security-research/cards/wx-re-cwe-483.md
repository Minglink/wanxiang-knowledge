# CWE-483: 不正确的块定界

## 缺陷定义

代码没有明确界定一个本应包含 2 条或更多语句的块，从而导致逻辑错误。

## 机制与扩展说明

在某些语言中，块的括号（或其他定界符）是可选的。当省略定界符时，可能会引入逻辑错误，导致某条语句被误认为在块内，但实际上并非如此。在某些情况下，这种逻辑错误可能具有安全影响。

## 可能后果及作用范围

此表指定了与该弱点相关的不同个体后果。“范围”识别被违规的应用安全领域，而“影响”描述如果攻击者成功利用该弱点所产生的负面技术影响。“可能性”提供有关相对于列表中其他后果，特定后果被预期的可能性信息。例如，某种弱点可能极有可能被利用以实现某种影响，但利用它来实现另一种影响的可能性则很低。

## 官方英文定义（核对锚点）

Incorrect Block Delimitation

The code does not explicitly delimit a block that is intended to contain 2 or more statements, creating a logic error.
