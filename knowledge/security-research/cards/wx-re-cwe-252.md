# CWE-252: 未检查返回值

## 缺陷定义

产品未检查方法或函数的返回值，这可能导致其无法检测到意外的状态和条件。

## 机制与扩展说明

程序员通常有两种常见的假设：“此函数调用永远不会失败”和“此函数调用是否失败无关紧要”。如果攻击者能够强制函数失败或返回非预期值，随后的程序逻辑可能会导致漏洞，因为产品处于程序员所假设的状态之外。例如，如果程序调用一个函数来降低权限，但没有检查返回值以确保权限已成功降低，那么程序将继续以更高的权限运行。

## 背景机制

许多函数会返回有关其操作成功与否的值。这将提醒程序是否需要处理由该函数引起的错误。

## 官方英文定义（核对锚点）

Unchecked Return Value

The product does not check the return value from a method or function, which can prevent it from detecting unexpected states and conditions.
