# CWE-122: 基于堆的缓冲区溢出

## 缺陷定义

堆溢出是一种缓冲区溢出，其中可被覆盖的缓冲区是在内存的堆部分中分配的，通常意味着该缓冲区是使用 malloc() 等例程分配的。

## 可能后果及作用范围

此表指定了与该弱点相关的不同个体后果。“范围”识别被违规的应用安全领域，而“影响”描述如果攻击者成功利用该弱点所产生的负面技术影响。“可能性”提供有关相对于列表中其他后果，特定后果被预期的可能性信息。例如，某种弱点可能极有可能被利用以实现某种影响，但利用它来实现另一种影响的可能性则很低。
影响
详细信息
DoS：崩溃、退出或重启；DoS：资源消耗（CPU）；DoS：资源消耗（内存）
范围：可用性
缓冲区溢出通常会导致程序崩溃。其他导致可用性丧失的攻击也是可能的，包括使程序进入无限循环。
执行未经授权的代码或命令；绕过保护机制；修改内存
范围：完整性、机密性、可用性、访问控制
缓冲区溢出通常可用于执行任意代码，这通常超出了程序隐式安全策略的范围。除了重要的用户数据外，基于堆的溢出还可用于覆盖内存中可能存在的函数指针，将其指向攻击者的代码。即使在未明确使用函数指针的应用程序中，运行时通常也会在内存中保留许多函数指针。例如，C++ 中的对象方法通常使用函数指针实现。即使在 C 程序中，底层运行时也经常使用全局偏移量表。
执行未经授权的代码或命令；绕过保护机制；其他
范围: 完整性、机密性、可用性、访问控制、其他
当后果是任意代码执行时，这通常可以用来破坏任何其他安全服务。

## 补充说明与边界

术语
关于“缓冲区溢出”一词存在严重的不一致，它可能有多种解释和用法。许多人将其理解为“写入超出缓冲区末尾”。其他人则将其理解为“写入超出缓冲区末尾，或在缓冲区开头之前”。还有一些人可能会将“读取”也包含在该术语中。

## 官方英文定义（核对锚点）

Heap-based Buffer Overflow

A heap overflow condition is a buffer overflow, where the buffer that can be overwritten is allocated in the heap portion of memory, generally meaning that the buffer was allocated using a routine such as malloc().
