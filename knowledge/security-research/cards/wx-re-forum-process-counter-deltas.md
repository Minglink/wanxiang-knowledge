# 进程性能观测：累计计数、瞬时值与差分窗口

CPU 累计执行时间和 I/O 累计字节，与工作集、句柄数等瞬时快照含义不同。前者需要两个有效样本及实际经过的时间才能得到速率，后者描述读取时刻的状态。

计算前核对 PID 与创建时间，防止 PID 复用把不同进程的计数相减。基线缺失、查询失败、计时异常或计数回退，都应保留为独立状态，不能统一填零。

报告 CPU 百分比还需说明是否按逻辑处理器数量归一化。同一累计时间在不同归一化口径下显示不同，不能仅根据百分比变化判断程序行为变化。

分析例（本库构造，未执行）：例如同一实例的读字节计数在0.5秒内增加1000，区间平均读速率为2000字节每秒；它不能说明整个窗口内读操作均匀发生，也不能证明产生了相同数量的磁盘物理访问。
