# CWE-291: 依赖 IP 地址进行身份验证

## 缺陷定义

该产品使用 IP 地址进行身份验证。

## 机制与扩展说明

IP 地址可以被轻易伪造。攻击者可以伪造发送数据包的源 IP 地址，但响应数据包会返回到被伪造的 IP 地址。为了查看这些响应数据包，攻击者必须嗅探受害者机器与被伪造 IP 地址之间的流量。为了实现必要的嗅探，攻击者通常会设法让自己处于与受害者机器相同的子网内。攻击者或许能够通过使用源路由来规避此要求，但如今源路由在整个互联网上大部分已被禁用。总之，IP 地址验证可以是身份验证方案中有用的组成部分，但不应将其作为身份验证所需的唯一因素。
