# CWE-761: 释放非缓冲区起始位置的指针

## 缺陷定义

产品对堆上分配的内存资源指针调用了 free()，但该指针并未指向缓冲区起始位置。

## 机制与扩展说明

这可能导致产品崩溃，在某些情况下，还可能修改关键程序变量或执行代码。
当使用 malloc() 系列函数在堆上显式分配内存并调用 free() 时，如果由于指针算术运算导致指针指向缓冲区内部或末尾，通常会出现此弱点。

## 可能后果及作用范围

此表指定了与该弱点相关的不同个体后果。“范围”识别被违规的应用安全领域，而“影响”描述如果攻击者成功利用该弱点所产生的负面技术影响。“可能性”提供有关相对于列表中其他后果，特定后果被预期的可能性信息。例如，某种弱点可能极有可能被利用以实现某种影响，但利用它来实现另一种影响的可能性则很低。

## 预防与缓解措施

缓解措施

在使用指针算术遍历缓冲区时，请使用单独的变量来跟踪内存进度，并保留最初分配的地址以便后续释放。
实施
在使用 C++ 编程时，考虑使用 boost 库提供的智能指针，以帮助正确且一致地管理内存。

## 官方英文定义（核对锚点）

Free of Pointer not at Start of Buffer

The product calls free() on a pointer to a memory resource that was allocated on the heap, but the pointer is not at the start of the buffer.
