# 回调重入审计：模式标志与数据解释必须保持一致

同一字段在不同模式下可能表示绝对指针或相对偏移。若控制解释方式的标志与字段内容不是一致更新，后续代码就可能按错误模式解释合法位模式。

原帖通过窗口扩展数据案例说明状态切换问题。审计时应把调用外部回调视为状态可能改变的边界，逐项检查回调前后的假设是否仍成立。

判断核心是数据与状态的联合不变量，不是只看某个字段是否非空。具体版本的结构偏移和接口行为应另外核对，本条未重现文章的漏洞与利用。

分析例（本库构造，未执行）：例如对象原先标为直接地址模式，回调改变为偏移模式，返回后旧代码却继续沿用原值。即便两个单独字段都通过了形式检查，组合后的解释仍可能错误。应验证联合状态。
