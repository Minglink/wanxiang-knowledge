# 进程树：PID 复用与父子关系的时间约束

PID 是生命周期内使用的数字标识，退出后可以复用。将进程实例记录为 PID 加创建时间，可避免把旧进程的记录嫁接到新进程。

构造父子候选关系时，父实例应早于或同时于子实例创建；若当前同 PID 进程创建得更晚，就不能把它认作当时的父实例。父进程已经退出时，当前快照也可能没有可匹配记录。

创建时间约束能够排除部分错误关系，但不等于独立证明完整创建链。进程快照、审计事件和实际创建过程各有证据范围，报告应保留无法验证的原因。

分析例（本库构造，未执行）：例如子实例在10:00建立，而当前占据其父PID的实例在10:05才建立，后者显然不能是当时的父实例。这是PID复用或快照不完整的线索，应避免生成确定的父边。
