# CWE-308: 使用单因素身份验证

## 缺陷定义

该产品在应需要多个因素的安全环境中使用了仅使用单一因素（例如密码）的身份验证算法。

## 可能后果及作用范围

此表指定了与该弱点相关的不同个体后果。“范围”识别被违规的应用安全领域，而“影响”描述如果攻击者成功利用该弱点所产生的负面技术影响。“可能性”提供有关相对于列表中其他后果，特定后果被预期的可能性信息。例如，某种弱点可能极有可能被利用以实现某种影响，但利用它来实现另一种影响的可能性则很低。

范围: 访问控制
如果单因素身份验证方案中的密钥被泄露，则可以进行完全身份验证。

## 预防与缓解措施

阶段
缓解措施
架构与设计
使用多个独立的身份验证方案，这可以确保——即使其中一种方法被泄露——系统本身在很大程度上仍然是安全的，不会受到损害。因此，如果可以使用多种方案，则应实施并要求它们——尤其是如果它们易于使用的话。

## 补充说明与边界

其他
虽然使用多种身份验证方案只是在身份验证之上增加了复杂性，但拥有这种冗余措施价值不可估量。在互联网上，使用薄弱、重复和通用密码的现象十分猖獗。

## 官方英文定义（核对锚点）

Use of Single-factor Authentication

The product uses an authentication algorithm that uses a single factor (e.g., a password) in a security context that should require more than one factor.
