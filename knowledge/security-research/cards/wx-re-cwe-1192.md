# CWE-1192: 片上系统 (SOC) 中 IP 模块的标识符不当

## 缺陷定义

片上系统 (SoC) 没有为其每个组件提供唯一、不可变的标识符。

## 机制与扩展说明

片上系统 (SoC) 由具有不同信任要求的多个组件 (IP) 组成。要求每个 IP 具有唯一的标识符，并应在 SoC 中的其他实体之间进行无歧义的区分。唯一的安全标识符被用于多种目的。大多数情况下，该标识符用于路由事务或执行某些操作，包括重置、检索敏感信息以及代表其他对象采取行动。
此弱点有几种变体
“缺失”标识符是指 SoC 未定义任何用于唯一标识 IP 的机制。
“不足”的标识符可能提供某些防御措施（例如，针对最常见的攻击），但它不能防止所有预期的攻击。
“配置错误”的机制是指机制虽然可用，但未被正确实现。
“被忽略”的标识符是指 SoC/IP 未应用任何策略，或者未能安全地根据标识符采取行动。

## 官方英文定义（核对锚点）

Improper Identifier for IP Block used in System-On-Chip (SOC)

The System-on-Chip (SoC) does not have unique, immutable identifiers for each of its components.
