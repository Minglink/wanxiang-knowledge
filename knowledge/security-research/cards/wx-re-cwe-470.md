# CWE-470: 使用外部可控输入选择类或代码（“不安全的反射”）

## 缺陷定义

产品使用包含反射的外部输入来选择要使用的类或代码，但它未能充分防止输入选择不当的类或代码。

## 机制与扩展说明

如果产品使用外部输入来决定实例化哪个类或调用哪个方法，那么攻击者可以提供值来选择意外的类或方法。如果发生这种情况，攻击者可以创建开发人员未预期的控制流路径。这些路径可能会绕过身份验证或访问控制检查，或者导致产品以意外的方式运行。如果攻击者能够将文件上传到出现在产品类路径 (
CWE-427
) 中的位置，或者向产品的类路径 (
CWE-426
) 添加新条目，这种情况将演变成灾难性的场景。在这些条件下，攻击者可以使用反射将新的恶意行为引入到产品中。

## 官方英文定义（核对锚点）

Use of Externally-Controlled Input to Select Classes or Code ('Unsafe Reflection')

The product uses external input with reflection to select which classes or code to use, but it does not sufficiently prevent the input from selecting improper classes or code.
