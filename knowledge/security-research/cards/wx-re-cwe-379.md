# CWE-379: 在权限不安全的目录中创建临时文件

## 缺陷定义

产品在目录中创建临时文件，该目录的权限允许非预期的参与者确定文件的存在或以其他方式访问该文件。

## 机制与扩展说明

在某些操作系统上，任何有足够权限访问该目录的用户都可能发现临时文件的存在。由于文件是可见的，因此使用该临时文件的应用程序可能会被识别出来。如果攻击者有权列出系统上的进程，他们就能获得有关用户当时正在执行的操作的信息。通过将此信息与用户正在运行的应用程序关联起来，攻击者可能发现用户的操作意图。由此，更高级别的安全防线可能会被突破。

Creation of Temporary File in Directory with Insecure Permissions

The product creates a temporary file in a directory whose permissions allow unintended actors to determine the file's existence or otherwise access that file.
