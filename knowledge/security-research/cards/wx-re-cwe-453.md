# CWE-453: 不安全的默认变量初始化

## 缺陷定义

该产品在默认情况下使用不安全或不够安全的值来初始化内部变量。

## 可能后果及作用范围

此表指定了与该弱点相关的不同个体后果。“范围”识别被违规的应用安全领域，而“影响”描述如果攻击者成功利用该弱点所产生的负面技术影响。“可能性”提供有关相对于列表中其他后果，特定后果被预期的可能性信息。例如，某种弱点可能极有可能被利用以实现某种影响，但利用它来实现另一种影响的可能性则很低。

范围：完整性
攻击者可能获取敏感数据或系统信息的访问权并进行修改。

## 预防与缓解措施

阶段
缓解措施
系统配置
当默认设置可能被用于滥用系统时，应禁用或更改它们。由于这些默认设置是随产品一起提供的，熟悉产品的潜在攻击者很可能知道它们。例如，应更改默认凭据或禁用相关联的账户。

## 官方英文定义（核对锚点）

Insecure Default Variable Initialization

The product, by default, initializes an internal variable with an insecure or less secure value than is possible.
