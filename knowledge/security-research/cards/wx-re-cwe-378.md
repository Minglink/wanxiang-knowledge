# CWE-378: 创建具有不安全权限的临时文件

## 缺陷定义

在没有适当措施或控制的情况下打开临时文件会使文件、其内容以及它所影响的任何功能容易受到攻击。

## 可能后果及作用范围

此表指定了与该弱点相关的不同个体后果。“范围”识别被违规的应用安全领域，而“影响”描述如果攻击者成功利用该弱点所产生的负面技术影响。“可能性”提供有关相对于列表中其他后果，特定后果被预期的可能性信息。例如，某种弱点可能极有可能被利用以实现某种影响，但利用它来实现另一种影响的可能性则很低。
影响
详细信息
读取应用程序数据
范围：机密性
如果临时文件可以被攻击者读取，文件中可能包含的敏感信息就会被泄露。
其他
范围: 授权、其他
如果该文件可以被攻击者写入，则该文件可能会被移动到攻击者原本无法访问的位置。这将允许攻击者获得选择性的资源访问控制权限。
其他
范围: 完整性，其他
根据存储在临时文件中的数据，攻击者有可能获得一个被信任为非恶意的额外输入向量。攻击者或许能够对数据结构、用户信息甚至进程所有权进行任意更改。

## 预防与缓解措施

阶段
缓解措施
需求
许多现代编程语言都提供了能够正确处理此情况的函数。较旧的 C 语言临时文件函数尤其容易受到攻击。
实施
确保使用适当的文件权限。这可以通过使用安全的临时文件函数来实现。临时文件应该只允许拥有该文件的进程进行读写。
实施
随机化临时文件名。这也可以通过使用安全的临时文件函数来实现。这将确保临时文件不会在可预测的位置创建。

Creation of Temporary File With Insecure Permissions

Opening temporary files without appropriate measures or controls can leave the file, its contents and any function that it impacts vulnerable to attack.
