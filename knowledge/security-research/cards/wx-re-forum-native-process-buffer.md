# Native 进程快照：可变长记录与 NextEntryOffset 边界

进程枚举的 Native 查询把一批记录放入调用者缓冲区。记录可能包含可变长内容，读取器必须以成功返回的有效范围为边界，检查下一条偏移是否仍落在范围内。

处理字符串时还要核对长度、地址范围与编码，不能假设都有终止零。查询缓冲区不足时，应按状态扩容重试并设置上限；失败的数据不能继续当作完整快照。

快照反映查询期间的观察。进程随时可能创建或退出，跨两次枚举拼接字段时应保留采样时间和实例标识，不能将数量变化直接认定为隐藏行为。

分析例（本库构造，未执行）：例如，返回有效长度只有1024字节，而下一条偏移会落到1200字节处，读取器就应停止并标记异常，不能因为申请的缓冲区更大而继续解析无效尾部。
