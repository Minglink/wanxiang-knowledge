# CWE-1257: 对镜像或别名内存区域应用了不当的访问控制

## 缺陷定义

硬件设计中的别名或镜像内存区域可能被硬件强制执行不一致的读取/写入权限。一个可能的结果是，不受信任的代理被阻止访问某个内存区域，但没有被阻止访问相应的别名内存区域。

## 机制与扩展说明

硬件产品设计通常需要实现内存保护功能，使特权软件能够定义隔离的内存区域和访问控制（读/写）策略。在设计中，隔离的内存区域可以定义在不同的内存空间上（例如系统物理地址、虚拟地址、内存映射 IO）。
每个内存单元都应被映射并分配一个系统地址，核心软件可以使用该地址对该内存进行读/写。将同一个内存单元映射到多个系统地址是可能的，这样对任何别名系统地址的读/写都将被解码到同一个内存单元。
这在硬件设计中通常用于冗余和简化地址解码逻辑。如果其中一个内存区域损坏或出现故障，硬件可以切换到使用镜像内存区域中的数据。如果地址解码单元在将较小的地址区域映射到完整系统地址时忽略了高位地址位，系统地址映射中也可能创建内存别名。
此类内存映射中可能存在的一个常见安全弱点是：硬件对别名内存区域执行的读/写访问保护可能不同，导致不受信任的代理被阻止访问某个内存地址，但却未被阻止访问相应的别名内存地址。这种不一致性随后可被用于绕过主内存块的访问保护，并读取或修改受保护的内存。
如果不受信任的代理能够更改地址区域的映射或修改内存区域大小，它也有可能出于恶意目的在系统地址映射中创建内存别名。

## 官方英文定义（核对锚点）

Improper Access Control Applied to Mirrored or Aliased Memory Regions

Aliased or mirrored memory regions in hardware designs may have inconsistent read/write permissions enforced by the hardware. A possible result is that an untrusted agent is blocked from accessing a memory region but is not blocked from accessing the corresponding aliased memory region.
