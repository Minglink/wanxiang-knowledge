# CWE-475: API 输入的未定义行为

## 缺陷定义

此函数的行为是未定义的，除非其控制参数被设置为特定值。

## 补充说明与边界

其他
Linux 标准基规范 (LSB) 2.0.1 对于 libc 对某些内部函数的参数设定了约束 [21]。如果未满足这些约束，则函数的行为是未定义的。直接调用此类函数的情况很少见。它们几乎总是通过系统头文件中定义的宏来调用，而该宏确保满足以下约束：必须将值 1 传递给以下文件系统函数的第三个参数（版本号）：__xmknod；必须将值 2 传递给以下宽字符字符串函数的第三个参数（组参数）：__wcstod_internal, __wcstof_internal, __wcstol_internal, __wcstold_internal, __wcstoul_internal；必须将值 3 作为第一个参数（版本号）传递给以下文件系统函数：__xstat, __lxstat, __fxstat, __xstat64, __lxstat64, __fxstat64

## 官方英文定义（核对锚点）

Undefined Behavior for Input to API

The behavior of this function is undefined unless its control parameter is set to a specific value.
