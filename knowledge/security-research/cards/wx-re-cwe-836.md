# CWE-836: 使用密码哈希而非密码进行身份验证

## 缺陷定义

产品在数据存储中记录密码哈希，从客户端接收密码哈希，并将提供的哈希与从数据存储中获取的哈希进行比较。

## 机制与扩展说明

某些身份验证机制依赖客户端生成密码哈希，可能是为了减轻服务器负载或避免通过网络发送明文密码。然而，当使用客户端生成哈希时，攻击者可以通过获取哈希副本来绕过身份验证，例如：通过使用 SQL 注入攻击获取身份验证凭据数据库，或利用信息泄露漏洞。攻击者随后可以使用修改后的客户端重放盗取的哈希，而无需知道原始密码。
因此，服务器端对客户端提供的哈希进行比对，其安全性并不比直接使用未经哈希处理的密码更高。

Use of Password Hash Instead of Password for Authentication

The product records password hashes in a data store, receives a hash of a password from a client, and compares the supplied hash to the hash obtained from the data store.
