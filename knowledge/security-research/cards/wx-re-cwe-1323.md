# CWE-1323: 敏感追踪数据的管理不当

## 缺陷定义

从片上系统 (SoC) 上多个来源收集的跟踪数据被存储在未受保护的位置，或传输给不受信任的代理。

## 机制与扩展说明

为了方便对复杂的片上系统 (SoC) 设计进行验证，SoC 集成商会添加特定的 IP 块，用于实时追踪 SoC 的内部信号。该基础设施能够实现对 SoC 内部行为的可观测性，验证其功能设计，并检测硬件和软件漏洞。这类追踪 IP 块从 SoC 上的多个源头收集追踪信息，包括 CPU、加密协处理器和片上互连 (on-chip fabrics)。从这些源头收集的追踪信息随后在追踪 IP 块内部进行聚合，并转发至追踪接收端（trace sinks），例如调试追踪端口，以便外部硬件和软件调试器进行调试。
由于这些追踪信息是从多个安全敏感源收集的，因此必须防止不受信任的调试器访问。如果这些信息存储在未受保护的内存中，不受信任的软件调试器可以访问这些追踪信息并提取秘密信息。此外，如果安全敏感的追踪信息未被标记为安全，不受信任的硬件调试器可能会访问它们以提取机密信息。

Improper Management of Sensitive Trace Data

Trace data collected from several sources on the
                System-on-Chip (SoC) is stored in unprotected locations or
                transported to untrusted agents.
