# CWE-192: 整数强制转换错误

## 缺陷定义

整数强制转换是指一组与原始数据类型的类型转换、扩展或截断相关的缺陷。

## 机制与扩展说明

多种缺陷属于整数强制转换错误类别。在大多数情况下，这些错误本身只会导致可用性和数据完整性问题。然而，在某些情况下，它们可能会导致其他更复杂的安全相关缺陷，例如缓冲区溢出条件。

## 可能后果及作用范围

此表指定了与该弱点相关的不同个体后果。“范围”识别被违规的应用安全领域，而“影响”描述如果攻击者成功利用该弱点所产生的负面技术影响。“可能性”提供有关相对于列表中其他后果，特定后果被预期的可能性信息。例如，某种弱点可能极有可能被利用以实现某种影响，但利用它来实现另一种影响的可能性则很低。

Integer coercion refers to a set of flaws pertaining to the type casting, extension, or truncation of primitive data types.
