# CWE-1233：缺少锁位保护的安全敏感硬件控制

## 缺陷定义

产品使用寄存器锁定位保护机制，但它不能确保锁定位能防止系统寄存器或执行重要硬件系统配置更改的控制被修改。

## 机制与扩展说明

集成电路和硬件知识产权 (IP) 可能提供设备配置控制，这些控制需要在设备电源重置后由受信任的固件或软件模块（通常由 BIOS/引导加载程序设置）进行编程。重置后，通常期望这些控制不能再被用于执行任何进一步的修改。这种行为通常使用受信任的锁定位来实现，该位可以被设置为禁用对受保护寄存器组或地址区域的写入。锁定保护旨在防止对特定系统配置（例如内存/内存保护单元配置）的修改。
然而，如果锁定位未能有效地对所有可能修改受保护系统配置的系统寄存器或控制进行写保护，那么攻击者可能能够利用软件访问这些寄存器/控制并修改受保护的硬件配置。

## 官方英文定义（核对锚点）

Security-Sensitive Hardware Controls with Missing Lock Bit Protection

The product uses a register lock bit protection mechanism, but it does not ensure that the lock bit prevents modification of system registers or controls that perform changes to important hardware system configuration.
