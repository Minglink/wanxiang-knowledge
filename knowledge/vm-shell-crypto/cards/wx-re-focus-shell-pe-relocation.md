# 重建映像：重定位状态决定地址能否换基址

## 机制

PE的基址重定位目录描述加载地址变化时需要调整的位置。内存映像中的相关值可能已由加载器修正；把它们写回文件时若保留错误基址或再应用一次偏移，会产生重复修正。记录应包含首选基址、实际基址、重定位类型和处理状态。

## 分析例与核对方法

本库构造：原始绝对地址为A+0x1000，当前加载在B后变为B+0x1000。若新文件宣称值仍以A为基础，下一次加载时再加B-A，最终指针就偏移两次。

## 判断边界

不是所有数值看起来像地址就应重定位，代码立即数与数据常量需要结合目录和使用证据区分。这里讨论映像一致性，没有提供对未知程序执行重建或绕过保护的自动命令。
