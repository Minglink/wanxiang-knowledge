# TEA识别：32位回绕、双字状态与轮常数

## 机制

原始TEA文献假定32位字，把两个状态字在重复周期中交替更新，并使用delta=0x9E3779B9。实现包含加法、异或和移位，按32位无符号回绕解释。分析时同时检查状态宽度、更新顺序、密钥索引和循环次数，常数只是线索。

## 分析例与核对方法

本库构造：同一伪代码在long为64位的平台上直接运算，会保留本应截断的高位，导致测试输出不同。复核应明确uint32语义和字节到字的映射；不能因为循环里有delta就认定标准TEA。

## 判断边界

原论文中的历史安全性措辞不是当前选型建议，本卡用于理解与兼容研究。变种可能修改周期数或组合方式，解出可读字节也不足以证明参数正确；应使用已知输入输出与中间状态交叉核对。
