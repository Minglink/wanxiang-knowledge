# Argon2id：内存、时间与并行参数不能折叠成一个成本

## 机制

RFC9106描述Argon2各变体及其内存使用模式。Argon2id组合不同访问方式，内存大小、遍数与并行度都参与计算。分析编码结果时应保留变体、版本、各成本参数、salt和输出，而不是把它们简写为一个“强度等级”。

## 分析例与核对方法

本库构造：两个实现使用相同口令与salt，但其中一个把内存参数按字节而另一个按规范单位解释，结果与资源消耗都会不同。应先核对单位和版本，再讨论性能或兼容性。

## 判断边界

内存硬度不是“绝对无法猜测”，低熵口令仍受输入分布影响。参数选择需要结合实际资源与服务负载测试，本卡没有给任何系统直接规定部署参数，也没有执行破解或压测。
