# 可重入解释器：VM执行片段之间的状态连续性

## 机制

可重入设计可以只执行若干次分发就返回，稍后从保留的VPC、栈和局部状态继续。因此应区分本机调用边界与虚拟任务完成边界。关联依据包括上下文对象身份、状态版本、恢复位置和外部可见结果。

## 分析例与核对方法

本库构造：第一次调用执行LOAD并保存VPC=12，第二次从12继续ADD；两个片段共享同一上下文。若把首次返回当成完整输出，就会误认为函数没有计算结果，或者把未完成状态当成错误。

## 判断边界

多线程、嵌套调用和对象复用可能使同一地址对应不同任务。需加入任务编号、时间和生命周期信息。这里是Tigress明确提供的一种解释器形态，并不说明任意高频短函数都采用这种机制。
