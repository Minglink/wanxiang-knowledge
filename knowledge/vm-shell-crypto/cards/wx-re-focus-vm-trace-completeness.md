# 吾爱研究归纳：跟踪缓存、记录字段与可解释性

## 机制

suno的公开原帖以OD跟踪介绍初始化、分发和处理器之间的关系，并提示缓存大小和记录内容会影响结果。归纳到研究记录中，至少应写清采集起止、线程、是否保存指令及栈/标志、缓存上限和停止原因。

## 分析例与核对方法

本库构造：日志只保留最近一万条，初始化在更早的位置。此时找不到上下文建立过程，不能据此认定VM没有初始化。应把“初始化未采到”写进证据边界，再用独立运行补采入口状态。

## 判断边界

原帖发布于2017年，示例是具体调试器和简单VM，界面快捷键不保证适用于今天的版本。高频块只能帮助定位候选，普通循环也会高频；本库未下载附件或运行原帖样本。
