# UPX：压缩层、恢复代码与原程序语义

## 机制

UPX手册描述对多种可执行格式的压缩和展开。包装后的文件包含启动恢复逻辑及压缩内容；运行时需要恢复可执行状态，再把控制交给应用。研究记录应分别保存磁盘结构、恢复过程和恢复后的执行映像，不把壳代码当成业务算法。

## 分析例与核对方法

本库构造：程序原本计算整数校验，压缩后入口先搬运与展开数据。观察到展开循环只能解释包装层，无法据此判断业务校验逻辑；应在恢复后的控制流中重新建立函数、数据与调用关系。

## 判断边界

UPX工具能否处理具体文件取决于格式和文件是否被二次修改；工具报错不证明样本采用高级VM。手册也提醒其继承被处理文件的安全上下文，本库只收录文献，没有执行未知文件。
