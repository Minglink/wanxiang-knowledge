# SHA-256识别：压缩函数与消息包装是两层

## 机制

SHA-256把填充后的消息分组送入压缩过程，最终输出状态字。逆向时应区分流式更新、最后填充和核心压缩函数。长度字段、输入编码及初始状态错误都可能导致完整摘要不同，即使局部轮计算看起来合理。

## 分析例与核对方法

本库构造：界面字符串“abc”在一处被编码为三个ASCII字节，另一处包含终止零字节，两者哈希本来就不同。应先确定实际输入字节与长度，再比对压缩状态，而不是从摘要差异直接推断算法变种。

## 判断边界

32字节输出还可能来自SM3、截断、密钥派生或其他摘要。无密钥哈希不能提供发送者身份认证；如果协议要求认证，还要观察密钥是否参与及是否有MAC层。本卡未执行标准向量。
