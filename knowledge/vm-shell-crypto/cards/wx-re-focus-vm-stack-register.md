# 虚拟栈与寄存器槽：按读写语义建立映射

## 机制

VM可以把原寄存器放到上下文内存槽，用另一组本机寄存器维护解释器。分析表中应分别写语义名、当前承载位置、位宽和映射生效区间。栈顶缓存会让部分压入/弹出没有立即内存写入，不能依赖单一写栈模式。

## 分析例与核对方法

本库构造：槽0先保存参数x，某处理器把它读入eax；后续eax用于地址计算，而x已经存到槽8。只把eax命名为x会污染后续分析，应该记录“槽0读出x→槽8写回x”的状态链。

## 判断边界

看雪所述VMP3.5.1案例区分物理寄存器轮转和上下文槽轮转，这两种映射变化需要独立追踪。该个案的槽数、偏移与承担寄存器不外推到其他版本；原帖工具效果也未在本库复现。
