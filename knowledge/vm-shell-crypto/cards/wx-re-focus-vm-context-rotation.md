# 看雪研究归纳：物理寄存器轮转与上下文槽轮转

## 机制

原帖VMP3.5.1案例中，vEIP等解释器角色会更换物理寄存器；上下文中保存原始寄存器的槽也可能交换。前者影响如何找字节码指针，后者影响如何解释槽的业务含义。把二者写入独立映射表，可避免错误传播。

## 分析例与核对方法

本库构造：片段A的esi代表VPC，片段B变成edi，同时槽0与槽4交换。若只更新VPC承载寄存器，字节码读取可能正确，恢复出来的参数却仍会互换；两张映射表都要随转移更新。

## 判断边界

这是对公开实验方法的归纳，没有核实作者全部工具输出，也没有把某个槽数或分支实现设为通用规则。若轨迹不覆盖映射变化点，后续槽位解释应标为未知，不能依照旧映射继续猜测。
