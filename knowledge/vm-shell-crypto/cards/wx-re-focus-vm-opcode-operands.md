# 虚拟字节码：操作码与操作数长度共同决定解码

## 机制

操作码通常选择语义，后续字节可能编码常数、槽位或分支目标。指令长度可能随类别变化。正确解码要记录取指前后VPC、实际读出的字节范围、数据宽度和符号扩展，避免把立即数误当下一操作码。

## 分析例与核对方法

本库构造：01后跟四字节立即数，02没有操作数。字节序列01 02 00 00 00 02可能表示PUSH 2与ADD，并非连续出现多条编号为02的指令。先观察五字节读取边界，再解释虚拟栈变化。
