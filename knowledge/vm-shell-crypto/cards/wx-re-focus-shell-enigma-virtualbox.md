# Enigma：文件虚拟化与代码虚拟机不能混为一谈

## 机制

Enigma产品页面同时出现许可、文件打包与代码保护等概念。文件虚拟化让应用通过封装层取得原本独立的资源，代码虚拟化则改变业务指令的表示与执行。研究记录应按实际对象区分资源访问和指令解释。

## 分析例与核对方法

本库构造：配置文件和图片被合到EXE后，程序依然执行普通CPU指令，只是读取资源的来源改变。此时研究资源映射有意义，但寻找虚拟操作码表可能完全偏离问题。

## 判断边界

同一产品家族可能同时支持多种能力，具体版本和配置必须单独核对。厂商关于“不可破解”等描述不能当成技术证明。品牌名、单文件大小和节名不足以判断是否发生函数虚拟化。
