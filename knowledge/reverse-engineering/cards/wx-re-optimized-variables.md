# 优化代码：变量不可见、内联与源码单步跳行

## 原理
优化后，源码变量和运行时存储位置不再是一一对应关系。常量传播可能消去存储，寄存器可被复用，指令可重排，函数也可被内联。调试信息只能描述仍可表达的对应关系。

## 判断例（本库构造）
源码写了 int x=3; return x+4;，生成代码可以直接返回 7。此时找不到 x 的独立内存位置是合理的，不等于发生了反调试，也不等于调试器损坏。

## 判断方法
先确认当前栈帧及变量作用域，再检查构建是否含调试信息、是否启用了优化。对关键结论以反汇编中的值传播为依据，必要时在调用前或入口处观察参数。自行构建的对照样本可保留调试信息并降低优化，用来验证源语言与指令的映射。

## 易错点
源码行号是指令到源码的映射，不代表 CPU 按源码行顺序执行。单步跳回前一行、某些行没有停靠点或局部变量不可显示，都可能是正常优化结果。
